# José Maza · portfolio-pro

Portafolio profesional principal (`jgmaza.vercel.app`). El catálogo gamificado vive en el repo `portfolio` (retro).

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- ES / EN locale toggle

## Dev

```bash
npm install
npm run dev
```

## Content

- `src/content/companies.ts` — timeline laboral
- `src/content/projects.ts` — proyectos por categoría + presentation
- `src/content/profile.ts` — bio, skills, links
